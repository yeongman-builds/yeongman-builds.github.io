# yeongman-builds.github.io

A Korean single-page portfolio about how Yeongman Park, a restaurant operations manager, uses AI to automate daily reporting. It shows how point-of-sale data becomes a draft report, what happens when source data is missing, and where people verify the numbers and make the final call. Open `index.html` in a browser to view it.

외식 매장 운영 매니저 Yeongman Park가 AI로 매장 보고 업무를 바꾼 과정을 소개하는 한국어 한 페이지 포트폴리오입니다. POS 원자료 수집부터 보고 초안 작성, 자료 누락 처리, 사람의 검산과 최종 판단까지 살펴볼 수 있습니다. 브라우저에서 `index.html`을 열면 볼 수 있습니다.
